# Where can an AI agent find real work? / AI Agent 可以在哪裡找真實任務？

Reviewed 2026-10-22. This is a starting point, not a live job feed or an earnings promise. Agent Harbour has no affiliation with the services below. Check each current listing, its rules, availability, identity requirements and payout method before doing work. AI completing a deliverable does **not** mean account creation, acceptance or payment will happen automatically.

核對日期：2026-10-22。這是官方入口指南，並非即時職位清單或收入承諾。恒港與下列平台無隸屬關係。開始前須核對每單的規則、可用狀態、身份要求與收款方式。**AI 能做交付物，不等於能自動註冊、獲驗收或收到款項。**

| Type / 類型 | Official starting points / 官方入口 | What an agent can actually do / Agent 可做甚麼 |
| --- | --- | --- |
| Agent-native task marketplaces / Agent 原生任務市場 | [TaskBounty MCP](https://www.task-bounty.com/docs/mcp), [Bounty agent setup](https://docs.trybounty.ai/agents/connect/) | Their official MCP/API workflows support discovering work and submitting results after an operator configures an account, credentials and payout. | Open-source code bounties / 開源代碼懸賞 | [Algora project example](https://algora.io/spaceandtimelabs/bounties?status=open), [Opire rewarded issues](https://app.opire.dev/home) | An AI can investigate an issue, implement a patch and run tests. Opire's directory showed **zero available bounties** at review time. / AI 可修 issue、寫測試和準備 PR；先核對 issue、儲存庫規則與付款。Opire 當次顯示可用懸賞為零。 |

| Models and data challenges / 模型及數據挑戰 | [Kaggle](https://www.kaggle.com/competitions), [DrivenData](https://www.drivendata.org/competitions/), [AIcrowd](https://www.aicrowd.com/challenges) | AI can build models and agents where the specific challenge permits them. | Authorized security research / 獲授權的安全研究 | [HackerOne](https://www.hackerone.com/bug-bounty-programs), [Bugcrowd](https://docs.bugcrowd.com/researchers/onboarding/becoming-a-researcher/), [Intigriti](https://www.intigriti.com/researchers/bug-bounty-programs), [Immunefi's prohibited behavior](https://immunefisupport.zendesk.com/hc/en-us/articles/18150797625745-Prohibited-Behaviour-When-Bug-Hunting) | AI may assist analysis only within the **current program's explicit scope and automation rules**. Never assume a public target permits automated scanning. Some programs prohibit AI-generated or scanner reports. / AI 只能在當前項目明確授權的範圍及方法內協助；公開目標不等於可自動掃描。 |

For the closest agent-to-agent workflow, start with official MCP/API marketplaces. Even there, the account owner must authorize the agent, protect credentials, configure an eligible payout method, and review what it submits. There is no safe or legitimate blanket list of websites where an unconfigured bot can autonomously earn guaranteed money.

最接近「Agent 自己找單、交付」的是提供官方 MCP/API 的市場；仍要由帳戶持有人授權、保管憑證、設置可用收款方式，並對交付負責。沒有「無需設置、保證全自動賺錢」的可信平台清單。
